# Historical documents / Documentos históricos

These documents and diagrams describe earlier build revisions. They are preserved
for development history, **not as installation instructions**. Some omit Monitor,
include an uninstalled VM divider, use different Hall thresholds, or show an
illustrative layout instead of a verified wiring diagram.

The current references are [hardware](../en/hardware.md),
[installation](../en/installation.md) and [configuration](../en/configuration.md).
The older scripts now live in [legacy](../../legacy/README.md).

Los documentos antiguos no representan necesariamente el montaje que funciona
actualmente. Usa [hardware actual](../es/hardware.md),
[instalación](../es/installation.md) y [configuración](../es/configuration.md).
`MONTAJE_ORIENTATIVO.png` es una ilustración generada, no un plano de conexiones.

## File guide / Guía de archivos

| Files | Historical purpose / Propósito histórico |
| --- | --- |
| `CONEXIONES_TECNICAS.*`, `CABLEADO_SIN_PCB.svg` | Earlier wiring revisions; some omit Monitor / Revisiones anteriores de cableado; algunas omiten Monitor |
| `ESQUEMA_FINAL.*` | Earlier proposed design; “FINAL” is the original filename, not its current status / Diseño anterior; «FINAL» es el nombre original, no su estado actual |
| `PRUEBA_CMCV.md` | Original command-input test / Prueba original de entrada |
| `PRUEBA_TB6612.md` | Motor, Hall and manual-menu experiments / Ensayos del motor, Hall y menú manual |
| `PRUEBA_CAMIONETA.md` | Temporary road-test logger / Registrador temporal de pruebas |
| `MONTAJE_IMAGEN_PROMPT.md`, `MONTAJE_ORIENTATIVO.png` | Illustration prompt and generated image / Prompt e imagen ilustrativa generada |

Statements such as “vehicle test pending” describe the revision when that document
was written. For installed-build status, read the [project introduction](../../README.md).
Frases como «prueba en vehículo pendiente» corresponden a aquella revisión;
consulta el [inicio actual](../../README.es.md) para el estado del montaje instalado.
